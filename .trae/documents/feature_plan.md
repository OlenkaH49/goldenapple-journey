# 金苹果之旅 - 功能计划表

## 📋 项目概述
一款面向初中/高中学生的英语背单词应用，采用 **阅读 → 收集生词 → 做题 → 评估** 的学习模式，结合AI智能分析和艾宾浩斯遗忘曲线复习法。

## 🛠 技术架构

### 前端 (index.html + app.js)
- 单页HTML应用，原生JavaScript
- CSS变量管理主题配色
- localStorage数据持久化
- DOM操作实现页面切换

### 后端 (server.js)
- Node.js + Express框架
- Coze AI工作流API集成
- 文件缓存（word_cache.json）
- SSE流式响应

### 数据结构
```javascript
// 用户数据
userData = {
    userName: 'string',
    level: 'A2/B1/C1',
    streak: number,           // 连续打卡天数
    lastDate: 'date',
    masteredCount: number,
    collectedWords: [{
        id: timestamp,
        word: 'string',
        meaning: 'string',
        sentence: 'string',
        article: 'string',
        status: 'pending/learning/mastered',
        knowledge: 0-1,
        collectedAt: 'ISO date',
        nextReview: 'ISO date'  // 艾宾浩斯复习时间
    }]
}
```
